# Screenshots

Add public, sanitized dashboard screenshots here.

Recommended Machine Health filenames:

```text
machine_health_environment.png
machine_health_performance.png
machine_health_storage.png
machine_detail.png
```

Before publishing a screenshot:

- Remove customer and user information.
- Remove internal hostnames when required.
- Do not expose credentials, tokens, tenant IDs, or subscription IDs.
- Use representative time ranges and readable browser zoom.
- Capture both the full page and selected high-value sections.

After adding screenshots, embed them in the root `README.md` using relative paths.
