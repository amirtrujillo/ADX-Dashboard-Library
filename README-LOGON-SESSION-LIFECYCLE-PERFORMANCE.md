# Logon & Session Lifecycle Performance

Azure Data Explorer dashboard for observing user logon and session lifecycle
behavior from uberAgent data.

## Highlights

- Logon duration and components
- Group Policy processing
- session concurrency and lifecycle
- logoff duration and components
- User, Host, Session, and Time range filtering

## Import

Use:

dist/Logon & Session Lifecycle Performance.adx.json

Then update the ADX_Observability data source to point to your ADX cluster
and database.
