# Installation — Browser & Web Experience

1. Download `dist/Browser & Web Experience.adx.json`.
2. Import the dashboard into Azure Data Explorer.
3. Edit the `ADX_Observability` data source.
4. Replace the public cluster and database placeholders with your environment.
5. Save the dashboard.
6. Set a Time Range that contains browser/web telemetry.
7. Confirm the Browser and Website parameters populate.
8. Select a website from a cross-filter-enabled tile and confirm the Website parameter updates.
