# Installation

1. Download the import-ready JSON from dist.
2. Import the dashboard into Azure Data Explorer.
3. Edit the ADX_Observability data source.
4. Replace:
   - https://your-cluster.your-region.kusto.windows.net/
   - your-database
5. Save the dashboard.
6. Confirm the Time range, Host, Operating System, Hardware Model,
   Application, and Update State parameters load.
7. Validate all four pages.

The release does not contain credentials, tokens, private cluster names,
private database names, or endpoint-identifying sample data.
