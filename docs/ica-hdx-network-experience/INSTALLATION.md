# Installation

1. Download ICA HDX Network Experience.adx.json from the dist folder.
2. Import the JSON file into Azure Data Explorer Dashboards.
3. Configure ADX_Observability to point to your ADX cluster and database.
4. Confirm the dashboard parameters load.
5. Validate that the dashboard queries return data for your environment.

The release JSON uses:

Cluster:
https://your-cluster.your-region.kusto.windows.net/

Database:
your-database
