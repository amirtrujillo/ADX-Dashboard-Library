# Citrix Infrastructure & Site Health v0.1.0

Initial public release of DASH-004.

## Included

- five dashboard pages;
- twenty-six tiles;
- six dashboard parameters;
- reusable KQL parameter and tile queries;
- Schema 78 importable dashboard JSON.

## Functional validation

The release candidate was validated in Azure Data Explorer.

Final validation changes included:

- query-reference uniqueness for Schema 78;
- Registration % visualization corrections;
- Maintenance mode Off / On formatting;
- VDA Power State Distribution redesigned as a time-based visualization.
