# Endpoint Inventory & Compliance

Azure Data Explorer dashboard for endpoint inventory and evidence-backed
compliance visibility.

## Included views

- Endpoint Overview
- Endpoint & Hardware Detail
- Software & Updates
- Network Inventory

The dashboard package includes import-ready JSON and reusable KQL queries.

## Release

- Version: v0.1.0
- ADX dashboard schema: 78
- Pages: 4
- Tiles: 15
- Parameters: 6

The public JSON uses cluster/database placeholders and does not include private
environment configuration.
