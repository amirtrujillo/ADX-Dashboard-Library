# Browser & Web Experience

Azure Data Explorer dashboard for browser and website experience analysis.

## Highlights

- Browser and website performance overview
- Website usage by users and hosts
- Page-load and request analysis
- Browser foreground experience
- Website CPU and memory allocation analysis
- Interactive Website cross-filter across dashboard pages
